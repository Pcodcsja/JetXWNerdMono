# Pico attribution and distribution notices

Pico is an independently maintained derivative font by Pcodcsja. It is not an official release of JetBrains, LXGW, Nerd Fonts, or the upstream merge project. Source project names identify attribution only.

## Sources and contributions

- JetBrains Mono NL: original Latin outlines and font design. Original designers include Philipp Nurullin and Konstantin Bulenkov; see source metadata.
- Nerd Fonts: patched Latin input and symbol collections. Font and icon licenses are distinct from the MIT license of Nerd Fonts tooling.
- LXGW WenKai Mono GB Screen and LXGW ZhenKai GB: CJK outlines, based in part on Klee by the Klee Project Authors / Fontworks.
- lvbibir/JetBrainsLxgwNerdMono: upstream font merging project and build implementation. Original contribution credit is retained.
- Pcodcsja: Pico maintenance, source updates, character-width fixes, CJK obliques, web splitting fixes and independent naming. This does not claim authorship of the original glyph designs.
